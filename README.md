# harnoorsagar.github.io/my-personal-website

My personal portfolio, built with React and Vite and deployed to GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

This builds the site and pushes `dist/` to the `gh-pages` branch.

## Updating content

All text, links, experience and projects live in `src/data.js`. Project images are in `src/assets/`, and the resume PDF is `public/Harnoor_Sagar_Resume.pdf`.
